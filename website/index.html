Privacy by Design

Phosphor uses Apple's Private Information Retrieval (PIR) with homomorphic encryption. Your device checks URLs locally using a Bloom filter. For potential matches, encrypted queries go through Apple's relay — we can't see what you're browsing.

Zero telemetry. No analytics SDKs. No crash reporters. Nothing phones home.

How It Works

Bloom Filter (On-Device)

A compact data structure instantly checks if a URL might be blocked. ~99.9% of URLs are cleared here with zero network traffic.

Encrypted PIR Query

For potential matches, the system sends a homomorphically encrypted query. The server processes it without ever decrypting it.

Apple's OHTTP Relay

Queries route through Apple's relay. Your IP is hidden from our server; query content is hidden from Apple. Neither sees both.

Block or Allow

The encrypted response is decrypted on your device. The app never learns which URL was checked.
